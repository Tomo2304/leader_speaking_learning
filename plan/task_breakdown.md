# Task Breakdown — Skills, Knowledge & AI Capabilities

*9 major tasks with what is needed for each.*

---

## Task 1 — Eliminate Weak Language Habits

| | |
|---|---|
| **Skills** | Self-awareness, habit recognition, pattern interruption under pressure |
| **Knowledge** | Which phrases are weak vs strong, why Japanese communication defaults differ from Western leadership norms |
| **AI can help** | Review emails or spoken drafts and flag weak language, suggest stronger replacements, give instant feedback |

---

## Task 2 — Internalise Top-Down Structure (BLUF / Pyramid)

| | |
|---|---|
| **Skills** | Structural thinking — identifying your conclusion before you speak or write |
| **Knowledge** | The Pyramid Principle, how executives process information, when depth is appropriate |
| **AI can help** | Restructure any draft, score structure, explain why a rewrite works better — act as editor |

---

## Task 3 — Framework for Spontaneous Speaking (PREP)

| | |
|---|---|
| **Skills** | Quick structuring under pressure, comfort with silence while thinking |
| **Knowledge** | PREP framework (Point, Reason, Example, Point), how to adapt to different question types |
| **AI can help** | Run live mock Q&A as a senior leader or executive, evaluate PREP responses and suggest improvements |
| **Note** | Voice practice best done with ChatGPT voice mode or Orai — Claude is text-only |

---

## Task 4 — Master Executive Communication

| | |
|---|---|
| **Skills** | Brevity, calibrating depth to audience, recommendation-first writing |
| **Knowledge** | What executives need vs want, how to signal you understand their level |
| **AI can help** | Edit real emails and presentations to executive-ready standard, explain every change, build templates |

---

## Task 5 — Build Meeting Facilitation Skills

| | |
|---|---|
| **Skills** | Active listening while formulating, redirecting without dismissing, closing decisively |
| **Knowledge** | Anchor phrases, meeting flow structures, how to hold the room without dominating |
| **AI can help** | Roleplay meeting scenarios — act as difficult stakeholder, rambling participant, or challenging senior leader |

---

## Task 6 — Develop Delivery and Presence

| | |
|---|---|
| **Skills** | Controlled pace, deliberate pausing, downward intonation, projection |
| **Knowledge** | How delivery signals confidence vs uncertainty, mechanics of shadowing practice |
| **AI can help** | Provide shadowing scripts, explain why delivery choices work, recommend what to listen for in specific clips |
| **Note** | Orai and BoldVoice are better for actual delivery feedback — they can hear you |

---

## Task 7 — Real-World Application

| | |
|---|---|
| **Skills** | Deliberate practice, courage to try new approaches in live situations, honest self-reflection |
| **Knowledge** | Knowing which framework fits which situation, how to prepare for high-stakes moments |
| **AI can help** | Prepare specifically for upcoming real situations, debrief afterwards, identify what to do differently |

---

## Task 8 — Track Progress and Adjust (3-Layer Monitoring)

| | |
|---|---|
| **Skills** | Honest self-assessment, identifying patterns across multiple situations |
| **Knowledge** | What good looks like at each milestone, how to measure communication improvement |
| **AI can help** | Act as consistent reviewer across the journey, compare responses over time, adjust the plan based on what is and isn't working. Automated weekly check-in via /schedule |

---

## Task 9 — Build Leadership Vocabulary and Language Bank

| | |
|---|---|
| **Skills** | Active vocabulary acquisition, applying new language naturally without sounding scripted |
| **Knowledge** | Leadership vocabulary, executive language, data analytics leadership terminology |
| **AI can help** | Build personalised vocabulary bank from real reviews, quiz on usage, rewrite actual work sentences and explain each choice. Any better phrasing found during review is added to vocabulary_bank.md automatically |
